# Fluxo

1. Leia `.codex/00_PROJECT_INDEX.md`.
2. Identifique a tarefa e leia somente o contexto indicado.
3. Inspecione o código real.
4. Separe fato, protótipo, proposta e pendência.
5. Para auditoria, não altere código.
6. Entregue evidências, lacunas, plano e riscos.
