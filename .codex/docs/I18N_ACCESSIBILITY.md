# i18n e acessibilidade

## Idiomas

Espanhol, português e inglês. Não duplicar páginas por idioma; usar a estratégia de tradução existente ou ADR.

## Regras

Traduzir labels, mensagens, validações, estados, e-mails e conteúdo editorial. Definir fallback e manter URLs estáveis.

## Acessibilidade

Orientação mínima: WCAG 2.1 AA, sem declarar conformidade antes de auditoria.

- HTML semântico;
- teclado;
- foco visível;
- labels;
- erros vinculados;
- contraste;
- não depender só de cor;
- texto alternativo;
- modais com foco;
- zoom 200%;
- alternativa textual para mapa;
- idioma declarado;
- redução de movimento.

Os modos de daltonismo do protótipo são complementares, não substituem esses controles.
