# Proteção de dados

Dados esperados: nome, e-mail institucional, EFS, autoria, histórico, anexos e logs.

- minimizar;
- separar contato interno de conteúdo público;
- informar finalidade;
- não publicar e-mail automaticamente;
- limitar administração;
- evitar dados reais em desenvolvimento;
- definir retenção e exclusão;
- não colocar dados pessoais em nome físico de arquivo.

Pendentes: aviso de privacidade, base legal, retenção, controlador/operador, cookies, transferência e canal de direitos.
