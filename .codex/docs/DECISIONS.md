# Decisões

## Aceitas

- Django existente como base;
- consulta pública;
- espanhol/português/inglês;
- hospedagem Hetzner AX42-1;
- segredos fora do Git;
- protótipo atualizado como referência após comparação com o código.

## Propostas

- PostgreSQL em produção;
- Nginx + Gunicorn;
- workflow explícito com histórico;
- conteúdo administrável em vez de embutido em JavaScript.

## Pendentes

SO do servidor, domínio/DNS, homologação, Docker ou systemd, e-mail, mídia/backup, monitoramento, privacidade, biblioteca do mapa, curadores e política de tradução.
