# UI

## Tokens

Use variáveis CSS para as cores do protótipo, fonte Raleway, raio principal de 16 px e largura máxima próxima de 1200 px.

## Componentes

Cabeçalho, cards, filtros, chips, modais, formulários em seções, estados vazios, paginação, alertas, Meu Espaço e mapa/painel.

## Estados

Carregando, vazio, erro, sucesso, desabilitado, foco, hover, validação e sem permissão.

## Responsividade

Testar 320, 768, 1024 e 1440 px. Filtros empilham, mapa tem alternativa em lista, ações críticas permanecem acessíveis.

## Conteúdo

Espanhol é referência. Datas/números seguem locale. Nenhum texto visível deve ficar sem estratégia de tradução.
