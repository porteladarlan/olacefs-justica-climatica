# Base de conhecimento

A leitura é progressiva. Comece por `00_PROJECT_INDEX.md`.

Classificações:

- `CONFIRMADO`: fonte ou decisão;
- `PROTÓTIPO`: comportamento do HTML atualizado;
- `PROPOSTA`: recomendação a validar;
- `PENDENTE`: informação ainda não confirmada;
- `ESTADO REAL`: evidência encontrada no código, banco ou testes.
