# Alterar modelo e migration

1. inspecionar models/migrations;
2. considerar dados existentes;
3. descrever alteração;
4. planejar compatibilidade;
5. criar migration pequena;
6. separar migration de dados;
7. definir rollback;
8. testar banco vazio e com dados;
9. executar `makemigrations --check --dry-run`;
10. não aplicar em produção automaticamente.
