# Fase 15D — Recursos técnicos

Implementação baseada na retroalimentação recebida.

## Objetivo

Ajustar a seção **Recursos técnicos** para não parecer uma área finalizada antes da definição pela consultoria auditora especializada e pelo laboratório de justiça climática.

## Alterações

- Substitui o texto antigo do Banco Técnico por uma seção institucional de **Recursos técnicos**.
- Informa que a área está em desenvolvimento.
- Explica que os conteúdos finais serão definidos em etapa posterior.
- Mantém a área preparada para:
  - estudos preliminares;
  - guias metodológicas;
  - documentos de referência;
  - marcos normativos comentados.
- Preserva a listagem de recursos cadastrados, caso existam registros no banco.
- Adiciona teste específico da Fase 15D.
