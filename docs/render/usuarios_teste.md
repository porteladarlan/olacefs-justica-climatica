# Orientação para usuários de teste

## Perfis necessários

### 1. Usuário comum / pessoa autora

Uso:

- acessar a plataforma;
- enviar boa prática;
- salvar rascunho;
- enviar para revisão;
- consultar Meus Envios.

Permissões esperadas:

- não deve acessar painel de revisão;
- deve acessar formulário de envio;
- deve acessar Meus Envios.

### 2. Usuário staff / pessoa revisora

Uso:

- acessar painel de revisão;
- analisar submissões;
- revisar edições publicadas;
- simular aprovação ou solicitação de ajustes.

Permissões esperadas:

- deve acessar `/painel-revisao/`;
- deve acessar `/painel-revisao-edicoes/`.

## Modelo para compartilhar credenciais

```text
URL:
Idioma sugerido:
Usuário:
Senha:
Perfil:
O que testar:
Observações:
```

## Cuidados

- não usar senhas pessoais;
- não usar dados sensíveis reais;
- deixar claro que o ambiente é de teste;
- apagar ou trocar credenciais após a rodada de teste;
- evitar anexos sensíveis durante validação.
