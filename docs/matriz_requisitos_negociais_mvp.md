# Matriz de Requisitos Negociais do MVP

| Requisito negocial | Implementação no MVP | Status |
|---|---|---|
| Plataforma como hub vivo de boas práticas | Catálogo, filtros, páginas de detalhe, favoritos e comparação | Implementado |
| Visualização pública | Catálogo, página inicial, normas, banco técnico e detalhes públicos | Implementado |
| Submissão mediante cadastro | Login, cadastro e bloqueio do envio para não autenticados | Implementado |
| Perfis: visitante, usuário, revisor, administrador | Visitante público, usuário autenticado, staff/revisor e admin Django | Implementado no MVP |
| Página introdutória sobre justiça climática | Página inicial com conceito e objetivo da plataforma | Implementado |
| Visualização de boas práticas | Catálogo e ficha detalhada | Implementado |
| Filtros principais | País, EFS, tipo, setor, tema, norma e ano | Implementado |
| Normas internacionais | Página própria e vínculo nas experiências | Implementado |
| Formulário para inserir boa prática | Formulário estruturado com campos negociais | Implementado |
| Salvar/continuar | Rascunho e edição antes de publicação | Implementado |
| Fluxo de revisão | Enviado, em revisão, aprovado, publicado, rejeitado | Implementado |
| Voltar para ajustes | Devolução para rascunho com comentário do revisor | Implementado |
| Edições após publicação passam por aprovação | Modelo de proposta de edição e painel específico | Implementado |
| Comparar experiências | Página de comparação e seleção pelo catálogo | Implementado |
| Favoritar/curtir experiências | Favoritos por sessão | Implementado para MVP |
| Banco de perguntas, critérios e ferramentas dentro da experiência | Campos na ficha da experiência | Implementado |
| Anexos PDF/Word/Excel | Upload validado e links externos | Implementado |
| Idiomas OLACEFS | PT, ES e EN nas principais telas | Implementado parcialmente no MVP |
| Visual institucional moderno | Header reorganizado, cards, hero e estrutura visual | Implementado |
| Homologação | Checklist e roteiro de testes | Implementado nesta fase |
