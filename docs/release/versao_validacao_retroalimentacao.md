# Versão de validação — Consolidação da retroalimentação

## Objetivo

Este documento consolida a versão de validação da Plataforma Regional de Boas Práticas em Auditoria com Perspectiva de Justiça Climática após a rodada de retroalimentação.

A versão atual está preparada para demonstração, validação interna e teste externo controlado com pessoas usuárias das EFS.

## Escopo consolidado

A plataforma contempla:

- página inicial institucional;
- catálogo público de boas práticas;
- ficha estruturada de experiências;
- formulário de envio de boas práticas;
- fluxo de rascunho, envio e revisão;
- painel de revisão;
- painel de revisão de edições publicadas;
- recursos técnicos;
- normas internacionais;
- suporte trilíngue em português, espanhol e inglês;
- dados demonstrativos para apresentação;
- auditorias técnicas de tradução, autenticação, perfis e fluxo ponta a ponta;
- materiais de apoio para teste externo;
- documentação técnica para ambiente de teste e produção futura.

## Fases implementadas

- Fase 15G — revisão visual das páginas públicas.
- Fase 15H — ajustes do formulário de envio.
- Fase 15I — ajustes do fluxo de revisão e aprovação.
- Fase 15J — conteúdo institucional, recursos técnicos e normas.
- Fase 15K — dados demonstrativos para apresentação.
- Fase 15L — usabilidade e acessibilidade.
- Fase 15M — revisão trilíngue final.
- Fase 15N — autenticação, perfis e permissões.
- Fase 15O — validação funcional ponta a ponta.
- Fase 15P — preparação para teste externo.
- Fase 15Q — preparação técnica de ambiente.

## Estado funcional

A versão atual está apta para:

- demonstração institucional;
- validação interna;
- teste externo controlado;
- coleta de feedback das EFS;
- planejamento de produção futura.

## Pontos que não devem ser tratados como produção final

A versão atual ainda não deve ser tratada como produção institucional definitiva, pois depende de decisões futuras sobre:

- ambiente oficial de hospedagem;
- banco de dados persistente;
- armazenamento definitivo de anexos;
- backup e restore;
- domínio oficial;
- governança editorial formal;
- política de usuários;
- eventual política de privacidade/termos de uso;
- conteúdo final dos recursos técnicos e normativos.
