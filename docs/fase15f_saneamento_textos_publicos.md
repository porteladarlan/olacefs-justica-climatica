# Fase 15F — Saneamento final de textos públicos e aderência à retroalimentação

Esta fase corrige inconsistências textuais remanescentes antes de avançar para novas funcionalidades.

## Ajustes aplicados

- Remove ocorrências públicas de `MVP` na página Sobre.
- Substitui linguagem de `ferramentas/tools/herramientas` por `metodologias e instrumentos` quando o contexto é metodológico.
- Remove a pergunta pública `Contribui para a Guia` do formulário de envio/edição.
- Remove a linha `Contribuição para a Guia` do comparador.
- Ajusta a tela de favoritos para falar em aprendizagem regional, não em exemplos para a Guia.
- Ajusta a tela de revisão de submissões para PT/ES/EN e para usar `perguntas, critérios e metodologias`.
- Ajusta a tela de revisão de edições publicadas para reduzir textos fixos em português.
- Adiciona testes de saneamento textual.

## Observação

Os campos técnicos existentes no banco de dados foram preservados para compatibilidade. A mudança desta fase é principalmente textual e de apresentação pública.
